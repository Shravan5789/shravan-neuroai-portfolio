# Shravan — Data Science & NeuroAI Portfolio

A responsive, static personal portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. Keep `styles.css`, `script.js`, and `assets/profile.png` in their relative paths.

## Included
- Responsive navigation and portfolio sections
- Portrait cropped from the provided photo
- GitHub, Instagram and email contact links
- NeuroAI explainer and an interactive synthetic signal sandbox for frequency, amplitude and modulation
- Cognitive topic cards covering attention, memory, sleep rhythms and perception

## Scientific note
The waveform is synthetic and illustrative only. It is not EEG data, does not infer a person's mental state, and is not a diagnostic or medical tool. The relative-power number is an arbitrary demonstration formula, not a clinical measurement.
